# 受保护模块变更方案

此目录只存放“仅修改 `engine/` 无法完成”时提交给编译器组或存储组的方案，不存放对受保护模块的实际代码修改。

## 适用模块

- `compiler-module.md`：对应 `minisql/`
- `storage-module.md`：对应 `页式存储系统/`

## 方案必须包含

1. 当前公开 API 与可复现的阻塞点。
2. 建议新增或调整的类、方法签名、参数和异常语义。
3. 为什么无法在 `engine/` 内通过适配器解决。
4. 对现有调用方和二进制/源代码兼容性的影响。
5. 由模块负责人实施的测试、回归验证和验收标准。

未获对应模块负责人批准前，任何提交都不得修改 `minisql/` 或 `页式存储系统/`。
